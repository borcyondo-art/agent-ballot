How it works

  1. Hold an Agent ID — the ballot checks it on-chain before every vote.
  2. One question is posted each day. The question text is public; only its hash is stored on-chain, so anyone can verify the text matches.
  3. Vote once per day: Yes or No. Your vote is one transaction you confirm in your own wallet.
  4. When the day is resolved, every voter who picked the outcome earns 1 point. Correct votes on consecutive days build your streak.
